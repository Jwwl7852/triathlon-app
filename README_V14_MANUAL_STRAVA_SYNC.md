# V14 Manual Strava Sync

Automatisk Strava-sync er stadig i appen, men der er nu også en tydelig manuel knap.

I Strava-fanen:
- Synk Strava nu
- Importer seneste Strava-data

Synk Strava nu:
1. Tjekker om Strava er forbundet.
2. Kører en forsigtig 30-dages sync i små sider.
3. Henter gemte aktiviteter.
4. Importerer dem i appen.
5. Matcher aktiviteter med planlagte træninger på samme dato/disciplin, hvis muligt.
6. Opretter ellers træningen som gennemført historik.

Dette giver kontrol, hvis automatisk sync ikke kører.
