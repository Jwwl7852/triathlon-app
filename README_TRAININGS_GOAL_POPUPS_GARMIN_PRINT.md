# Træninger, mål-popups, Garmin eksport og print

Ændringer:
- Program viser kun fremtidige planlagte træninger.
- Ny fane: Træninger, hvor tidligere/importerede aktiviteter ligger.
- Mål-kort er klikbare og åbner prognose-popup.
- Det store IRONMAN MÅL dashboardfelt skjules.
- Garmin-eksport er tilføjet som kalenderfil (.ics) med pace/intervaller/noter.
- Print uge er gjort mere kompakt til én side uden notelinjer.
- Månedsstatus får grøn gennemsigtig progress-linje ud fra gennemført procent.

Note:
Direkte Garmin Connect API-upload kræver Garmin partner/adgang. Derfor bruges først en stabil .ics-eksport.
