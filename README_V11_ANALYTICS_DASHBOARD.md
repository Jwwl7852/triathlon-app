# V11 Analytics dashboard

Ny Analyse-fane inspireret af TrainingPeaks / Intervals-agtige dashboards.

Indeholder:
- KPI-række
- Performance management light
- Completed duration/distance pie charts
- Planned duration/distance pie charts
- Duration/distance by week
- Planlagt duration/distance by week
- Gns. puls og maks puls over tid
- Run pace over tid
- Bike speed over tid
- Månedstabel
- Længste workouts
- Heart-rate zone light
- Weight chart hvis vægtlog findes

Dette er første version. Næste trin kan være rigtig CTL/ATL/TSB, TSS, power zones og HR zones fra Strava streams.
