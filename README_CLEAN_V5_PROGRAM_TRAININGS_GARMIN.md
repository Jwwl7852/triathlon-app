# Clean v5

Rettet uden at ændre dashboard-kerne.

- Program viser kun fremtidige ikke-gennemførte træninger.
- Træninger viser historik: tidligere datoer og gennemførte/importerede pas.
- Program-tabellen har en synlig Garmin-kolonne lige efter Plan.
- Garmin-knappen opretter en struktureret workout pr. træning og downloader .FIT.
- JSON backup kan downloades til fejlsøgning.

Automatisk sync direkte til Garmin Connect kræver Garmin Training API-adgang/approval.
