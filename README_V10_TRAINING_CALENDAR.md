# V10 Training calendar

Ny Kalender-fane inspireret af TrainingPeaks.

- Månedskalender mandag-søndag.
- Alle træninger vises på datoen.
- Grøn = gennemført tæt på plan.
- Gul = gennemført med afvigelse/delvist.
- Rød = tidligere træning uden data, sprunget over eller syg/skadet.
- Blå = fremtidig planlagt træning.
- Klik på en træning åbner redigering.
- Månedsskift frem/tilbage og "I dag".
