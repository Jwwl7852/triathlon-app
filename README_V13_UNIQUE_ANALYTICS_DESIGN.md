# V13 Unique Analytics Design

Analyse-fanen er redesignet, så den ikke ligner TrainingPeaks.

Nyt koncept:
- Performance Cockpit
- mørkt, eget visuelt udtryk
- ring-KPI'er for balance, planmatch, rytme og momentum
- Coach lens med indsigter
- heatmap over træningsrytme
- discipline lanes for svøm/cykel/løb/styrke
- egne trendkort og records

Eksisterende data og funktioner bevares.
